# 틈틈이 '두뇌 게임' 문제 작성 규칙

하루 두 판(오전 판 06:00, 저녁 판 17:00), 판마다 3문제. 모든 문제는 **최상 난이도**(아이큐 140, 상위 1~2%가 애써야 풀 만한 수준)로 만든다.
앱은 틀리면 "틀렸어요"만 보여 주고 정답은 절대 보여 주지 않는다. 그래서 **정답이 딱 하나**인 것이 가장 중요하다.

## 난이도: 최상으로 고정
- 한눈에 보이는 규칙 금지. 규칙 두 개 이상이 겹치거나, 3단계 이상 추론해야 풀리게.
- 잘 푸는 사람이 3~10분 생각해야 하는 수준. 쉬운 문제를 섞지 않는다.
- 그래도 공정해야 한다: 필요한 정보는 모두 문제 안에 있고, 전문 지식·암기·외국어 실력이 필요 없어야 한다
  (알파벳 순서, 사칙연산, 나머지, 자릿수, 제곱 정도의 기초 수학은 써도 된다).
- 종이와 머리로 풀 수 있게. 큰 수 계산(세 자리 × 세 자리 이상), 컴퓨터로만 셀 수 있는 경우의 수는 금지.

## 정답은 딱 하나
- 다른 해석, 다른 규칙으로 다른 답이 나올 여지가 없어야 한다.
- 수열·행렬은 규칙을 좁힐 만큼 충분히 보여 준다(수열은 6항 이상). 그럴듯한 다른 규칙이 보인 항에 모두 들어맞으면 실패.
- 논리 문제는 모든 경우를 따졌을 때 조건을 만족하는 경우가 정확히 하나여야 한다(verify 코드로 전수 확인).
- 보기형(choice)은 보기 5개 중 규칙을 만족하는 것이 정확히 하나. 오답 보기도 그럴듯하게.
- 문장은 한 가지 뜻으로만 읽히게. "~보다 크다/작다", "이웃", "사이", "왼쪽" 같은 말은 정확히 정의한다.

## 종류(판마다 서로 다른 종류 3개)
| kind | 내용 | 입력 |
|---|---|---|
| 수열 | 숫자가 늘어선 규칙. 두 수열이 번갈아 나오기, 차의 차, 연산 번갈아, 자릿수 규칙 등 겹친 규칙 | number |
| 행렬 | 3×3·4×4 숫자 칸의 빈칸. 행과 열이 함께 맞아야 하는 규칙 | number |
| 논리 | 사람·요일·자리·직업 배치. 단서 5~7개로 하나로 정해지게 | choice 또는 number |
| 참거짓 | 참말만 하는 사람·거짓말만 하는 사람의 말로 추리 | choice 또는 number |
| 수리 | 계산보다 발상이 필요한 문제(나이, 시계, 저울, 도형 세기, 경우의 수 등) | number |
| 암호 | 글자·숫자 바꾸기 규칙을 찾아 새 낱말을 바꾸기 | text 또는 number |
| 기호 | 3×3 기호 칸(●○■□▲△◆◇★☆ 등)의 규칙, 빈칸에 들어갈 것 고르기 | choice |

## 형식(후보 파일: 문제 객체의 배열, JSON)
```json
{
 "kind": "수열",
 "title": "짧은 제목(12자 이내)",
 "text": "문제 설명(300자 이내, 줄바꿈 \n 가능)",
 "clues": ["단서 1", "단서 2"],
 "grid": [["3", "8", "?"], ["5", "12", "31"]],
 "ask": "마지막 질문 한 줄 (예: ?에 들어갈 수는 무엇일까요?)",
 "input": "number",
 "choices": ["보기1", "보기2", "보기3", "보기4", "보기5"],
 "unit": "개",
 "answer": "정답(number는 숫자 문자열, choice는 1~5 번호 문자열, text는 짧은 낱말)",
 "hint": "방향만 알려 주는 한 문장. 답이나 핵심 계산 결과를 드러내지 않기",
 "explanation": "풀이 3~6문장. 규칙과 정답까지 써도 됨(맞힌 사람에게만 열림)",
 "verify": "def solve():\n    ...\n    return {'answer': ..., 'solutions': 1}"
}
```
- `clues`, `grid`, `choices`, `unit`은 필요할 때만. `grid`의 빈칸은 "?".
- `verify`: 파이썬 표준 라이브러리만 쓰는 `solve()` 함수. 20초 안에 끝나야 한다.
  - `answer`: 코드가 직접 계산한 정답(위 answer와 같아야 함). choice면 1~5 번호.
  - `solutions`: 조건을 만족하는 경우의 수. 논리·참거짓은 전수 조사한 개수, choice는 규칙을 만족하는 보기 개수. 반드시 1.
  - 수열·행렬은 규칙 함수로 보인 항·칸을 모두 다시 만들어 맞는지 확인(assert)하고 빈칸 값을 계산한다.
- 말투는 해요체. 휴대폰 한 화면에서 읽을 수 있게 짧게. 단서는 7개 이하.
- 기존 IQ 검사(멘사 등), 퍼즐 책·사이트의 문제를 베끼거나 숫자만 바꾸지 않는다. 새로 만든다.
- 사람 이름은 흔한 한국 이름(민준, 서연 등)이나 A·B·C로. 실존 인물·브랜드 금지.

## 세 번 확인(pipeline/RUNBOOK_BRAIN.md)
1. 코드 확인: `python3 pipeline/brain.py check 후보파일` — verify를 실행해 정답이 같고 경우의 수가 1인지.
2. 따로 풀기: 정답·풀이를 지운 파일을 다른 에이전트가 처음부터 풀어 같은 답이 나오는지.
3. 반박 검사: 또 다른 에이전트가 "다른 답도 되는지, 문장이 두 가지로 읽히는지, 너무 쉬운지"를 찾는다. 하나라도 걸리면 버린다.
